<Warning>**Mudança:** A partir de [data do deploy], a chave de API (`rnk_`) só é aceita em `https://api.renkecrm.com/v1/...`. Chamadas com a chave em endereços sem `/v1` (por exemplo, `https://api.renkecrm.com/opportunities`) recebem 401. Para corrigir, acrescente `/v1` ao caminho; o resto da chamada não muda.</Warning>

## Rate limit

As requisições são limitadas por chave + IP. Ao exceder o limite, a API responde `429 Too Many Requests`.

<Warning>**Em breve:** limites documentados por chave/tenant e headers `X-RateLimit-Limit`, `X-RateLimit-Remaining` e `Retry-After`.</Warning>

Boas práticas: use *backoff* exponencial em 429 e 5xx, e prefira webhooks a *polling*.

## Códigos HTTP

| Código | Significado |
| --- | --- |
| `200` / `201` | Sucesso |
| `400` | Corpo ou parâmetros inválidos |
| `401` | Chave ausente, inválida ou revogada |
| `401` | Chave de API usada fora de `/v1`. Mensagem: `Chave de API só é aceita na API pública /v1` |
| `403` | Escopo insuficiente ou `tenant-id` diferente do tenant da chave |
| `404` | Recurso não encontrado, ou rota que não faz parte da API pública |
| `409` | Conflito (ex.: registro duplicado) |
| `429` | Limite de requisições excedido |
| `5xx` | Erro interno — tente novamente |

## Formato do erro

```json
{
  "statusCode": 400,
  "message": "name: obrigatório",
  "error": "Bad Request"
}
```
